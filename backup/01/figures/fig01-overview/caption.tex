\textbf{Figure 1: Quantitative characterization of the OmniPath Metabo database contents.}\space
\figpanel{a}{Workflow architecture of the OmniPath ecosystem — upstream resources flow through download and processing in \texttt{omnipath-resources}, three parallel database builds (\texttt{omnipath-utils}, \texttt{omnipath-build}, \texttt{omnipath-metabo}), three web services (\texttt{utils.omnipathdb.org}, \texttt{omnipathdb.org}, \texttt{metabo.omnipathdb.org}), and the R and Python clients. The Metabo column features MetalinksDB, the COSMOS prior-knowledge network, and the server-side RDKit cheminformatics layer; MetalinksDB is built as a materialised view inside the main OmniPath Postgres database during the main build and is exposed by the Metabo web service.}
\figpanel{b}{Faceted resource overview across six record-type facets (Entities, Associations, Interactions, Identifiers, Structures, Literature). Each (facet, resource) cell carries two adjacent horizontal bars: the top bar splits items into \textit{unique} (dark) — contributed by that resource alone — and \textit{shared} (light) — also present in at least one other resource; the bottom bar breaks the same total down by major class (entity types, ontology classes, interaction-class vocabulary, identifier types, structural-specificity levels, or literature-id type, as appropriate). Resources are grouped into three magnitude bands (\textit{large}: $\geq$ 100K, \textit{medium}: 10K--100K, \textit{small}: \textless 10K) so the ChEMBL-scale tail does not crush the rest onto an invisible scale; each band has its own x scale. The \texttt{Total} row at the top of the large band uses the same shared / unique split with whole-database semantics — items supported by exactly one resource (\textit{unique}) vs.\ two or more (\textit{shared}). Structures facet routes to \texttt{dev4}; all other facets route to \texttt{dev3}.}
\figpanel{c}{Coverage profile: for each of the variants \textit{Entities}, \textit{Molecular entities}, and \textit{Structures}, the number of items supported by at least N resources, on a log y axis. The drop-off rate is the per-variant shape of the contribution overlap distribution.}
\figpanel{d}{Resource-overlap networks for two content kinds: \textit{Molecular entities} (left) and \textit{Interactions} (right). Nodes are resources; edges are pairwise overlaps from \texttt{resource\_overlap\_summary}, thresholded at $\geq$ 100 and rendered with log-scaled thickness. A single Kamada-Kawai layout is computed on the union graph and reused across both networks so each resource sits at the same screen position.}
\figpanel{e}{Entity-type $\times$ interaction-class matrix: per-participant-type relation counts (top eight participant types by total relation count) split by interaction-class vocabulary (\texttt{Signaling}, \texttt{Transport}, \texttt{Other}). The cycle-001 predicate vocabulary only populates these three classes; finer categories (TF-target, allosteric, ligand-receptor, drug-target) collapse into \texttt{Other} until the next vocabulary refresh.}
\figpanel{f}{Structural specificity $\times$ chemical category: for six chemical categories — drugs, lipids, food compounds, amino-acid metabolism, nucleic-acid metabolism, and carbohydrates — the number of entities at each of the six specificity levels (\texttt{stereospecific}, \texttt{cis\_trans\_only}, \texttt{constitution\_only}, \texttt{variable\_constitution}, \texttt{unknown\_constitution}, \texttt{no\_structure}). Read from \texttt{metabo\_entity\_structural\_specificity} on \texttt{dev4}; the \texttt{no\_structure} bucket is rendered as counted — \texttt{dev4} is pre-T020 chemical-fallback resolution so a substantial fraction of chemicals are still structure-less hashes.}
\figpanel{g}{RaMP identifiers that map to multiple distinct InChIKeys, classified by reason (\texttt{stereo}, \texttt{specificity}, \texttt{tautomer}, \texttt{similar}, \texttt{unrelated}). Classification is computed in-database by the cycle-001 RDKit Postgres cartridge and read from \texttt{metabo\_ramp\_inchikey\_conflict} on \texttt{dev4}.}
