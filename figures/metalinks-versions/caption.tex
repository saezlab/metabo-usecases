\textbf{Figure 4: MetaLinksDB~2.0 versus prior metabolite-protein interaction resources --- coverage, class breadth, and an in-depth view of MetaLinksDB~2.0.}
MetaLinksDB~2.0 compared with prior metabolite-protein interaction resources on a shared HMDB and UniProt counting basis.
\textbf{(a)} Overall interaction, metabolite, and protein coverage across the included resources (FR-010a). Interactions, metabolites, and proteins are reported as separate bars; counts are de-duplicated within each dimension.
\textbf{(b)} Coverage across metabolite classes using ChEBI-oriented class labels where available (FR-010b).
\textbf{(c)} Coverage across UniProt-derived protein classes with Guide to Pharmacology refinement where available (FR-010c).
\textbf{(d)} MetaLinksDB~2.0-only overview: interactions, metabolites, and proteins as a grouped bar chart along the resource axis the network was built from (chembl, hmdb, cellinker, …) (FR-010d).
\textbf{(e)} Relationship-type composition restricted to the three key categories \texttt{transport}, \texttt{receptor}, and \texttt{interaction}, comparing the included resources (FR-010e).
Baseline resources without a reproducible normalized snapshot are excluded and listed in the provenance sidecar. Per-panel supplementary CSVs of the underlying metabolite-protein interaction rows are emitted to \texttt{out/supplementary/4A..4E/} together with a central \texttt{legend.csv} explaining each file (FR-010h, FR-010i).
