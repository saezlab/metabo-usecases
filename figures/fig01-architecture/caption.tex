\textbf{Figure 1: Architecture of the OmniPath Metabo ecosystem.}\space
\figpanel{a}{Workflow diagram showing the OmniPath Metabo database build and serving stack — upstream resources at the top flow through download and processing in \texttt{omnipath-resources} (formerly \texttt{pypath}); three parallel database builds (\texttt{omnipath-utils}, \texttt{omnipath-build}, \texttt{omnipath-metabo}) each backed by its own PostgreSQL instance; three matching web APIs (\texttt{utils.omnipathdb.org}, \texttt{omnipathdb.org}, \texttt{metabo.omnipathdb.org}); and the R / Python clients at the bottom. The Metabo column features the MetalinksDB materialised view, the COSMOS prior-knowledge network, and the server-side RDKit cheminformatics layer. Headline counts shown on the diagram (entities, metabolite-protein interactions, structures, annotations) are sourced from the FR-043 statistics digest at \texttt{figures/fig01-architecture/panel-a-stats/} and are pinned to the snapshot identifier recorded in the figure's provenance sidecar.}
