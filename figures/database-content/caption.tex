\textbf{Figure 2: Quantitative characterization of the OmniPath Metabo database contents.}\space
\figpanel{a}{Faceted resource overview across six record-type facets (Entities, Associations, Interactions, Identifiers, Structures, Literature references), restricted to the whole-database \texttt{Total} row. Each facet carries two horizontal bars: the top bar splits items into \textit{unique} (dark, at the base of the bar) — supported by exactly one resource — and \textit{shared} (light, stacked above) — supported by two or more resources; the bottom bar breaks the same total down by major class (entity types, association classes, interaction-class vocabulary, identifier types, structural-specificity levels, or literature-reference type, as appropriate). Each facet has its own colour legend below it.}
\figpanel{b}{Resource-overlap networks for three content kinds: \textit{Molecular entities}, \textit{Interactions}, and \textit{Literature references}. Nodes are resources, node size scales with the resource's content count (log-scaled, $\sim$1k items render as a small dot and $\sim$1M items as a clearly larger circle); edges are pairwise overlaps from \texttt{resource\_overlap\_summary}, edge thickness scaled to overlap count (log-scaled). For the molecular-entities sub-panel, thin edges below the 70\textsuperscript{th} percentile of overlap weight are pruned so the strongest overlaps remain readable. A single Fruchterman-Reingold layout is computed on the union graph and reused across all three networks so each resource sits at the same position in every sub-panel.}
\figpanel{c}{Structural specificity by chemical category. Vertical facets group entities by chemical-class / metabolic-domain bucket; x-axis is the six-level structural-specificity ladder from \texttt{stereospecific} (fully resolved stereo) to \texttt{no\_structure} (no structural information). Log-scaled y where the dynamic range warrants it.}
\figpanel{d}{Entity × interaction-type matrix. Vertical facets by entity type (proteins / genes, metabolites, lipids, drugs, …); x-axis is the interaction-class vocabulary (\texttt{Signaling}, \texttt{Transport}, \texttt{Other}, plus any classes the build's vocabulary exposes). Each facet bar reports the count of interactions in which that entity type participates under that interaction class.}

All counts trace to recorded SQL queries against the dev5 integrated build and are reproducible from the figure's provenance sidecar (FR-008, SC-003). The headline counts the diagram in Figure~1 carries are the FR-043 statistics digest at \texttt{figures/architecture/panel-a-stats/}; this Figure 2 surfaces the distributional structure those headlines summarise.
