## Capture instructions

When the Metabo web service is ready (Assumption 3 in
`specs/001-figures-pipeline/spec.md`):

1. Open `https://metabo.omnipathdb.org/` in a clean browser window
   (Chromium / Firefox).
2. Search for `azelaic acid` (or the canonical HMDB id
   `HMDB0000784`).
3. Land on the entity detail page; expand the annotation and the
   metabolite-protein-interaction sections.
4. Capture the full visible page at 2x device pixel ratio (use the
   browser DevTools' device-toolbar or `--force-device-scale-factor=2`).
5. Crop to remove the URL bar / browser chrome but keep the page
   header for context.
6. Save as `panel_C_azelaic_acid.png` (PNG, transparent-free
   background) and overwrite the placeholder here.
7. Update this README's "Placeholder status" table below with the
   capture date, browser version, and SHA-256 fingerprint.
