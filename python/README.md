# Python helpers

Thin Python helpers shelled out from the R-side pipeline. Managed by
[`uv`](https://docs.astral.sh/uv/).

## Setup (on beauty)

```sh
cd ~/dev/metabo-usecases/python
uv venv .venv
uv pip sync uv.lock   # after the lockfile is first generated by `uv lock`
```

## Modules

- `utils/log.py` — configures Python logging to write to
  `$METABO_FIGURES_LOG` in the unified pipeline log format
  (see `specs/001-figures-pipeline/contracts/log-format.md`).
- `compose/svg_assemble.py` — SVG-level composite assembly using
  `svgutils`. Invoked by `R/compose/mixed_source.R` when SVG-native
  placement is required.
- `cosmos_pkn/build_pkn.py` — refactored from the case-study script
  `omnipath_metabo_case1/scripts/01_cosmos_pkn.py`; produces PKN slice
  files consumed by Figure 5 Panels E–F.

All helpers MUST call `utils.log.configure_pipeline_log("<component>")`
in their `if __name__ == "__main__":` block before any other logging.
